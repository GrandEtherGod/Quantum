# Supplied-source integration map

This release reconciles the September 2026 source set into one authority model. A source may contribute names, requirements, experiments, or training examples; it cannot grant executable authority.

| Source | Admitted contribution | Boundary |
|---|---|---|
| VERATH v4 Master Architecture | Canonical L0–L27 registry and engineering translations | Literal physics and ASI claims remain Temple or research-only |
| Technomicon Chimera Core Blueprint | Forge/Temple/Bridge lanes, Four Gates, bounded personas | Personas do not imply consciousness or authority |
| Sovereign Mind Architecture | Epistemic manipulation and anomaly-taxonomy prompts | The artifact's own validation failures are retained; anomalous phenomena are not capabilities |
| ZPE Thermodynamic Severance | Energy/thermal monitoring requirement | Casimir or vacuum-energy harvesting is unsupported and cannot power the runtime |
| H-field measurement schema | Reproducible quantum-job metadata and null-model discipline | `synchronicity_score` is exploratory and never field evidence by itself |
| Coding Pet brief | `.codepet` project state, scan manifest, journal, review-first proposals | No autonomous apply, shell, network, or self-rewrite authority |
| Ascendant Being | Consent, non-domination, humility, observation/inference separation | Spiritual language is contemplative, not empirical or clinical authority |
| AXIUS Site Guide skill | Canonical public-safe catalog, local transcript, consent boundaries | No arbitrary DOM/provider input, visitor-answer storage, or external action |
| VERATH–Theia Custom LLM Forge | Offline corpus, LoRA scripts, model card, behavioral gates | Training has not run; weights, ASI, consciousness, and universal alignment are not claimed |

## Authority rule

Only Forge components with ordinary software tests can influence execution. Bridge components translate a metaphor into a measurable proxy and stop rule. Temple components remain symbolic or research-only. Unapproved Bridge Contracts cannot promote Temple material into runtime control.

## Bundled packages

`tools/llm_forge/` is the supplied training-ready package. Its own status states that model weights have not been trained. `reference/source-bundles/axius-site-guide/` preserves the supplied reusable Site Guide bundle; the runtime's dependency-free catalog/export core is in `loom_verath/site_guide.py`.
